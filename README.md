# SYMBION

A language optimized for human-AI co-thinking.

## Vision

Human language is optimized for communication.

Programming languages are optimized for execution.

SYMBION is optimized for reasoning.

The goal of SYMBION is to create a shared medium through which humans and AI systems can think together more effectively by making assumptions, uncertainty, evidence, and relationships explicit.
