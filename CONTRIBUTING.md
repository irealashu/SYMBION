# Contributing to SYMBION

Thanks for contributing to SYMBION — a language optimized for human-AI co-thinking!

## How to contribute

- Issues: Search existing issues first. Open an issue with a clear title and a short description of the problem or feature, including steps to reproduce (for bugs) or a short motivating example (for feature requests).
- Discussions: Use Discussions for design, ideation, and questions that aren’t bugs.
- Pull requests: Fork the repo, create a feature branch, push commits, and open a PR against `main`. Link related issue(s) in the PR description and explain the motivation.

## PR checklist

- Describe the change and why it’s needed.
- Include tests for new behavior where appropriate.
- Ensure the project builds and tests pass locally.
- Keep changes focused and provide a concise summary in the PR.

## Commit and branch guidelines

- Branches: use descriptive names, e.g., `feat/xxx`, `fix/yyy`, `docs/zzz`.
- Commits: write clear messages; consider Conventional Commits (feat, fix, docs, chore).
- Rebase or squash when appropriate to keep the history tidy.

## Code style & tests

- Follow the project's formatting and lint rules (add specific tools to this section when added).
- Add or update tests for new features or bug fixes.

## Reporting security issues

- Do NOT open public issues for security vulnerabilities. Contact the maintainers directly at the email listed in the repository (or create a private disclosure channel).
