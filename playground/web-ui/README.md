# web-ui

This folder contains experimental web UI code for SYMBION.

Add a small frontend demo or scaffold here (React, Vite, or plain HTML/JS) to explore UI interactions with the language runtime.

Suggested files:
- `README.md` (this file)
- `src/` — frontend source
- `package.json` — for npm scripts and dependencies

Quick start (example):
1. cd playground/web-ui
2. npm install
3. npm run dev

Notes:
- Keep this folder lightweight and experimental — intended for demos and prototypes only.
